# ♟️ Chess Gaming JS

Um jogo de xadrez desenvolvido com HTML, CSS e JavaScript.

## 🎮 Acessar o jogo

### [♟️ Clique aqui para jogar Chess Gaming JS](https://laturb7z.github.io/chess-gaming-js/)

## ⚙️ Funcionalidades

- Xadrez clássico e Chess960.
- Modo jogador contra computador com Stockfish 19.
- PvP local.
- Salas PvP online com Firebase (em desenvolvimento).
- Histórico de movimentos e replay de partidas.

## 💻 Tecnologias

HTML5 · CSS3 · JavaScript · Firebase · Stockfish
